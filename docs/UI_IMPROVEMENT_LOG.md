### 已修复

1. **快速创建时间输入被忽略**：Blazor 会把 HTML `time` 输入值规范化为带秒格式；原 `HH:mm` 解析不接受规范化值。新草稿适配器接受含秒/小数秒输入。[上游依据](https://raw.githubusercontent.com/dotnet/aspnetcore/v10.0.0/src/Components/Web.JS/src/Rendering/Events/EventTypes.ts)
2. **跨日草稿丢失结束日期**：调整结束时刻保留原结束日期；开始日期/时刻变化保留时长。全天开关可恢复已输入的定时时间。
3. **全天结束日期难理解**：快速创建显示包含当天的结束日期，领域草稿继续使用不含结束日的原有契约；提供天数/时长摘要。
4. **无 autofocus 的弹层异常**：空目标检查不再误调用 `focus()`；排除隐藏、禁用元素，分离弹层不抢焦点，卸载移除监听器。
5. **手机周视图隐藏选中日期**：首次进入测量选中列并定位；周、日及不同小时范围独立保存双轴滚动位置，返回不重新吸附。
6. **横向滚动后时间标尺消失**：固定表头角标、全天标尺与时间标尺，偏移只处理浏览器几何，不修改事件时间。
7. **弱元数据和焦点可读性**：提高浅色/深色辅助文字对比度，独立焦点/链接色，声明原生控件色彩方案。
8. **手机快速创建布局**：并列开始/结束输入，44px 操作区、底部安全区、清晰主次动作；保留用户草稿和原有服务调用链。
9. **手机日期范围被截断**：窄屏显示紧凑月/日范围，完整年份范围保留在无障碍名称和提示中，桌面仍显示完整日期。
