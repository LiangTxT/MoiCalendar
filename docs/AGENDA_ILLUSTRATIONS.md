# 日程视图季节插画

原创素材由内置 ImageGen 生成，使用 Impeccable 的界面规范控制布局，未复制 Google 日历素材。

素材：`src/MoiCalendar.App/wwwroot/images/agenda-seasons-v1.png`。
一张三列四行图集，从左到右、从上到下对应一月至十二月；通过 CSS 定位使用，不依赖远端图片，支持离线缓存。

生成提示：制作十二个月的原创季节日历插画图集，三列四行，无间距、文字、数字或标志；一月冰河、二月雪村、三月萌芽河岸、四月花园、五月草地小屋、六月雨湖、七月绿荫、八月田野、九月收获、十月秋林、十一月街屋、十二月雪山。克制的编辑插画，分层景物与低饱和色彩；配色以 #F3F3EF、#283033、灰绿、#4AAAB6、#CF9138 为主，仅少量 #E1C443；横幅上方预留标题空间，不生成 UI，不照搬 Google。
