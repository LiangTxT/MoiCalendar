# 主题化表单选择器

## 设计依据

参考 [Adobe React Spectrum DatePicker](https://react-spectrum.adobe.com/DatePicker) 的输入字段与日历组合，以及 [Radix Select](https://www.radix-ui.com/primitives/docs/components/select) 的选项、键盘导航和焦点处理。仅参考交互原则，没有引入 React 依赖或复制其源代码。

按 Impeccable 的操作型界面规范保留现有主题令牌。按 Motion Ref 的弹层建议：桌面使用 200ms 淡入展开、窄屏使用 240ms 底部面板动效；减少动态效果时关闭动画。

## 边界

- `formPickerModel.js`：民用日期、六行月历、日期移动、分钟格式、视口边界。日期计算使用 UTC 日期分量避免受运行设备的夏令时影响；不负责事件的时区转换。
- `formPicker.js`：一个活动控件弹层，纯临时草稿；隐藏字段承接原有 Blazor 绑定，确认后发送标准 `input/change` 事件。业务校验仍由应用服务处理。
- `dateTimePicker.js`：日期和时间由普通按钮单击或 Alt+下打开网页选择器；显式“手动输入”入口才聚焦文本框，不聚焦原生日期／时间字段。
- 使用 Popover top layer 避免裁切；弹层 DOM 位于原有编辑器内，与共享编辑器的焦点边界协作。Escape 只取消最内层控件；外部点击取消；确认恢复触发按钮焦点。
- 时间列包含 24 小时、60 分钟；手动输入使用明确的 `HH:mm`，不执行十五分钟取整。日期网格支持方向键、Home/End、PageUp/PageDown。
- 选项与日期值通过 textContent 创建，不解析用户文本为 HTML。控件不直接写 IndexedDB、调用云服务或决定重复事件的变更范围。

## 固定 24 小时制（2026-10-10）

原生 `input[type=time]` 的显示格式由设备／浏览器决定，即使字段值为 `23:52` 也不能保证显示为 24 小时制。快速创建和完整编辑器的 `TemporalInput` 时间字段改用明确的 `HH:mm` 文本及 00–23 小时格式校验；以 `data-temporal-type=time` 继续使用现有主题选择器，保留单击选择、双击输入和一分钟精度。不支持增强选择器时可直接输入，不调用文本字段的原生时间面板。日期字段不变，既有事件不做迁移或时间转换。

新增组件渲染、午夜边界、主题选择与取消的回归测试。在独立 Edge 手机尺寸测试环境创建 `23:52` 至次日 `00:22` 的测试事件，并通过详情确认持久化时间正确；没有改动公网用户数据。模拟浏览器测试不替代真实 Android Edge 或 iPad Safari。
# 日期时间控件视觉统一（2026-10-06）

快速创建与完整编辑器复用 `TemporalInput`：按用户最新要求移除左侧图标，日期与时间均为居中的 24px、400 字重，使用标准宽度 `D-DIN`，失败时回退项目字体。保留主题淡底、6px 圆角和清晰的焦点边框。整框仍由原生 input 接收单击、双击与键盘输入；选择面板沿用已有逻辑，保持一分钟精度及取消草稿行为。仅在增强选择器可用时隐藏右侧原生图标，失败时仍可回退。

字体来源：https://github.com/amcchord/datto-d-din 。原版 WOFF（约 26KB）和 OFL 1.1、FONTLOG 文件一并保存于 `wwwroot/fonts/d-din/`，未经修改；中文标签保持原字体。CSS 相对路径加载、`font-display: swap`，使用既有 `.woff` 预缓存规则，无第三方 CDN 或额外网络运行依赖。

完整编辑器通过 `EventDateTimeFields` 将年月日与时分拆成独立输入，不合并或转换为 UTC；修改日期保留时间，修改时间保留日期，全天事件只显示日期，结束日期仍不包含当天。手机继承单列布局；动效遵循减少动态效果设置，高对比模式使用系统颜色。

验证：642 项 .NET 测试、34 项日期时间选择器脚本测试通过。D-DIN 字体资源测试及本地发布构建通过，发布清单包含字体；未进行真实浏览器离线或字体视觉验证。

## iPad 单一选择器（2026-10-11）

以下行为取代上文历史记录中的“双击输入／原生降级”：日期、时间与提醒的可见入口改成普通按钮，绑定字段隐藏。打开和关闭面板都不聚焦原生控件，避免网页弹层与 iOS 系统选择器叠加。未增强的其他下拉仍只使用原生选择器，不拦截它们。

日期／时间在网页弹层中选择，点一次“确定”应用；提醒点选选项后立即应用并关闭。全天提醒的默认 `07:00` 及自定义时间复用同一控件。显式“手动输入”才弹出键盘，输入无效时不可确定；取消不写入草稿，改回图形选项时同步手动输入的显示值。数据格式、时区及提醒业务规则未修改。

独立 Edge 合成触摸环境实操：创建 `23:52` 至次日 `00:22` 事件并核对详情、单次选择提前 5 分钟、取消日期修改、全天提醒默认 `07:00`、保存自定义 `08:25` 后重新编辑读回。检查 iPad 竖屏 768×1024、横屏 1024×768、手机 390×844 和桌面 1280×900 的弹层边界。测试数据仅在独立本地浏览器中，无公网数据变动。

合成触摸和视口模拟不替代真实 iPad Safari／主屏幕 PWA 验证；本机没有连接真实 iPad。预览控制台有 favicon 404，未见应用脚本异常。已有 PWA 更新提示遮住底部编辑按钮时，使用键盘打开编辑器，不能将这一步计作触摸通过。
