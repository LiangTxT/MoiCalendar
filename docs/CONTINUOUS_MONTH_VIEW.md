# 连续月视图方案

## 目标

- 保留 MoiCalendar 的本地优先边界，不依赖网络获取节日数据。
- 月视图采用大月份标题、固定星期栏、宽松日期单元格、农历副标签和彩色全天信息条。
- 向上或向下滚动时连续进入相邻月份，工具栏标题同步更新。
- 用户事件仍来自 IndexedDB；内置节假日与节气是只读展示数据，不写入用户仓储，也不进入同步队列。

## 结构

`ContinuousMonthView` 始终渲染“上月／当前月／下月”三个面板。浏览器把当前月定位在滚动容器中间；当相邻面板成为主要可见面板时，组件通知页面切换月份，页面重新补齐新的相邻月，并把相同可见月份放回中间，因此可以持续向两个方向滚动。

月份切换时并行读取三个 42 天窗口，继续通过 `CalendarEventService` 和仓储接口访问本地数据。日期选择、双击新建和事件拖动仍复用已有交互意图。

## 本地日历信息

`ICalendarObservanceProvider` 是 Core 中的只读边界。当前实现 `ChineseCalendarObservanceProvider` 在设备上计算：

- 元旦、劳动节、国庆节；
- 春节、元宵节、端午节、中秋节；
- 二十四节气；
- 日期格中的农历月份或农历日。

这些条目使用稳定标识、全天语义和只读标记合并到月／周／日程投影，不创建数据库记录。将来如需精确的法定调休安排，应新增带版本的本地数据包，而不是依赖联网接口或把调休规则写死在 UI 中。
