# MoiCalendar 自托管字体

本目录中的 WOFF2 文件来自 [Fontsource font-files](https://github.com/fontsource/font-files)，仅包含拉丁字符子集，并保留 Regular（400）、Medium（500）和 Semibold（600）三个实际使用的字重。

中文字符不下载额外的大型字体包；界面优先使用设备已安装的 Noto Sans SC / Noto Serif SC，再回退到苹方、微软雅黑、宋体等系统字体。因此系统字体模式不需要下载任何自定义字体，其他模式也不会依赖第三方字体服务器。

- Inter — SIL Open Font License 1.1，见 `LICENSE-Inter.txt`

- Space Grotesk — SIL Open Font License 1.1，见 `LICENSE-Space-Grotesk.txt`
